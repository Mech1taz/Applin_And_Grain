# Applin & Grain – Frontend

1. `npm install`
2. Copia tu logo a `public/logo.png`
3. Levanta ms-pedidos360-catalog en el puerto 8080
4. `npm run dev` → http://localhost:5173

Endpoints esperados: `GET /api/products` y `GET /api/products/{id}`.
Ajusta `mapProduct` en `src/services/catalogService.js` si tu DTO usa otros nombres de campo.
